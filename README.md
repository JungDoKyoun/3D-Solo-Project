## 🏗️ 주요 시스템 설명

### 플레이어 상태 시스템
State Pattern을 활용하여 플레이어의 다양한 상태(Idle, Move, Jump, Attack 등)를 관리합니다.

### 인터페이스 시스템
```csharp
- IIdle: 대기 상태
- IMove: 이동 및 회전
- ICheckIsGround: 지면 체크
- IFallenAndLanding: 낙하 및 착지
- IJump: 점프
- IUpStair: 계단 오르기
- ISloop: 경사면 처리
- IAttack: 공격
```

### 애니메이션 시스템
플레이어의 이동 속도에 따라 자동으로 애니메이션이 전환됩니다:
- 속도 0: Idle 애니메이션
- 속도 0~3.5: Walk 애니메이션
- 속도 3.5 이상: Run 애니메이션
